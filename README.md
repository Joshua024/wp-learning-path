# WP Mastery Path

A structured WordPress learning path — from Support Dev to WP Architect.

## Overview

This is a hands-on curriculum built around WordPress internals, hooks, filters, CRUD, and the HC3 Timber/Twig stack. Designed for 1 hour/day of focused learning.

## Phases

- **Phase 1** — PHP Foundations for WordPress
- **Phase 2** — WordPress Hooks — The Core Mental Model

## Usage

Open `index.html` in a browser to view and track your progress through the curriculum.
